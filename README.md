## 📖 Descripción del Proyecto
Este repositorio contiene la planificación, gestión e implementación simulada de un clásico juego de la **Serpiente (Snake)** desarrollado bajo metodologías ágiles (Scrum). 

El objetivo principal del juego es controlar una serpiente dentro de una cuadrícula, dirigirla para comer manzanas que reaparecen aleatoriamente, aumentar la longitud de su cuerpo y sumar puntos, evitando chocar contra los límites del escenario o contra sí misma.
